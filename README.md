# Product and Customer Management System
## About
A Java application for managing organization information, customer details, and product data using Object-Oriented Programming (OOP).
## Features
* Store customer information.
* Add and display products.
* Display organization and order summaries.
## Technologies
* Java
* Object-Oriented Programming (OOP)
